# 🎮 Instructor Setup Guide — GitHub Workshop

**Quick version:** Create one template repo with the README. Share the link. Students fork it. Done.

---

## 📋 Before class (10 minutes of setup)

### 1. Create the template repo

1. Go to github.com → **New repository**
2. Name: `mrkt441-digital-strategy-workshop-template`
3. Description: `Team template for MRKT 441 in-class workshop`
4. Set to **Public** ✅
5. Check **"Add a README file"**
6. Create repository

### 2. Add the README

1. Click the README.md file → ✏️ edit icon
2. Delete everything
3. Paste in the full contents of the `README.md` from this package
4. Commit changes

### 3. Make it a template

1. Go to your repo → **Settings**
2. Check **"Template repository"** at the top
3. Now anyone can click "Use this template" to get a clean copy

### 4. Share the link

Post this on Canvas before class:

```
📌 In-class workshop today!

Your team will fork this repo and commit answers during 5 timed rounds:
https://github.com/[your-username]/mrkt441-digital-strategy-workshop-template

ONE person per group clicks "Use this template" → "Create a new repository"
Name it: mrkt441-[yourteamname]
Add your teammates as collaborators.

Post your team's repo URL in Canvas before class ends.
```

## 🎯 During class

### Opening (first 5 min)
- Project the workshop game board on the big screen
- Have students form 6 groups of 4–5 students
- Each group draws a brand from a hat (or assign randomly)
- **One person per group forks the template** on their laptop — that's the "team captain"
- Captain adds teammates as collaborators so everyone can edit

### Between rounds
- Advance the round using the **Next round →** button on the game board
- Start the timer for each round
- Walk around — peek at commits on GitHub Desktop to see who's keeping up
- 2 minutes before timer ends, call out: "Last 2 minutes — commit now or lose it!"

### Grading tip
All commits are timestamped on GitHub. After class, open each team's repo and check:
- Did they commit all 5 rounds?
- Quality of writing (especially Round 2 stylistic twists and Round 3 reallocation logic)
- Commit history shows whether they worked throughout or rushed at the end

Suggested 20-point rubric:
- 4 pts — Round 0 & setup (team formed, brand picked, committed on time)
- 4 pts — Round 1 (correct gen/harvest identification + creative rewrite)
- 4 pts — Round 2 (complete SWOT + value prop; extra credit for creative voice)
- 4 pts — Round 3 (budget sums to $10k; reasoning is channel-aware; plot twist completed)
- 2 pts — Round 4 (correct A identification + remix attempted)
- 2 pts — Round 5 (all 3 steps of crisis response filled in)

## 🛠️ Common issues + fixes

**"I don't have a GitHub account"**
→ 60-second signup at github.com. Don't waste class time — send them to do it now while others form groups.

**"My teammate can't edit"**
→ Captain needs to add them as collaborator: Settings → Collaborators → Add people → enter GitHub username.

**"We lost our commit"**
→ GitHub autosaves every commit. Go to the repo → "History" or commits tab → previous version is there.

**"We don't know markdown formatting"**
→ Tell them not to worry. Plain text inside the `>` quote blocks is fine. Formatting doesn't matter — content does.

**"Can we use Google Docs instead?"**
→ No — the point is to give them a real industry skill (version control) while doing marketing work. But if a group is really stuck, have them paste into the README last minute.
